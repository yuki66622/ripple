# 冻结规则的执行边界

在子分支接触其真实分析结果之前确定；不改变CONTRACT中的参数。

- 第2形状要求满60分钟，按已有文字可以从01连续至已授权02；月份按t0归属。第5明确要求同月完整120分钟，维持原限制。
- 第5任何一个tier资产缺失或B=0，则整个event-tier无效，不能少资产取中位数。恢复时间中位数取含右删失总体累计>=50%确认时的最早时点（经验生存分位数），不在两个位置之间插值。
- 第7普通对照以control时点c±120分钟排冲击，不扩大成30分钟窗的外扩边界。该区间必须完整且有既有检测器覆盖；每月index<65未知，不能当作无冲击。
- 原始12列CSV不存在显式volume_valid，explicit_invalid计数为0并标注字段不存在；推导有效性单独保留。未来模型标记不能代替它。
- 模型比较的Top3资产数沿用B，报告3/N机会水平；N=3时Top3恒等于100%，不能误解为预测能力。完整tier的75%/50%只用于第1项。
- 图谱仅有January冻结版本，第二月不可虚构图谱；总表标January-only。
